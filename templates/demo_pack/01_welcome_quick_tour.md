# Welcome + Quick Tour

Welcome to the PyPad demo pack.

## Fast Tour

1. Open **File > Templates > Demo Pack**.
2. Use **New From Demo** to load a full sample in a new tab.
3. Use **Insert Demo** to add sample blocks into the current tab.

## Try The Play Layer

1. Open **Play > Productivity Hub**.
2. Open **Play > Daily Briefing** to see today's quest and companion guidance.
3. Open **Play > Productivity Routine** to launch the top suggested workflow.
4. Open **Play > Gamification Dashboard** to inspect quests, secret trails, and routine usage.

## What You Should Notice

- The status area shows live XP and quest progress.
- The momentum banner surfaces the current next move.
- The Productivity Hub collects:
  - quests
  - unlocks
  - seasonal events
  - session review
  - milestones
  - secret trails
  - routines
  - routine history

## Useful Shortcuts

- `Ctrl+N` new file
- `Ctrl+O` open file
- `Ctrl+S` save file
- `Ctrl+F` find
- `Ctrl+Shift+P` command palette
- `Ctrl+Alt+P` quick open

## What To Try Next

- Open `Markdown Showcase` template.
- Open `Export Fidelity Demo` template and export to HTML, PDF, DOCX, or ODT.
- Open `AI Workflow Demo` and test prompts.
- Use **Play > Coach Recommendation** after editing for a context-aware next action.
